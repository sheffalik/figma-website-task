# Clove Dental — Section 1

Static landing section: header, hero, consultation form, stats bar.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173).

## Assets

- Replace `assets/logo.svg` with the full Figma logo export if needed.
- Add `assets/hero.webp` (or update `index.html` to point at your hero image). Until then, a gradient placeholder shows behind the copy panel.
